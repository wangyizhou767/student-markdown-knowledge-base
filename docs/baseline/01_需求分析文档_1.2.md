# 大学生个人 Markdown 笔记与知识管理工具需求分析文档

> 文档状态：改进提交版 1.2  
> 当前基线：D-001～D-066  
> 功能需求、非功能需求、验收标准、追溯矩阵和技术可行性结论已经需求方逐项及整体人工确认。

## 1. 文档目的

本文档用于定义一款面向大学生的 Windows 本地优先 Markdown 笔记与知识管理工具，明确其用户、场景、系统范围、功能结构、业务规则和非功能约束，并为后续设计、实现和测试提供依据。

## 2. 背景与问题陈述

大学生的课程笔记、作业资料、实验记录、图片和零散知识通常分布在不同文件夹或应用中，容易出现难以查找、缺少关联、迁移困难和分享格式不统一等问题。本产品帮助学生将上述资料整理成可检索、可关联、可导出分享的本地知识库。

## 3. 产品定位与目标

### 3.1 产品定位

- 面向大学生的个人知识管理工具。
- Windows 优先的桌面应用。
- 本地优先、无需注册，核心功能离线可用。
- 使用通用 Markdown 文件保存内容，用户拥有并控制自己的数据。

### 3.2 产品目标

- 降低课程笔记和作业资料的整理成本。
- 通过目录、标签和双向链接建立多维知识结构。
- 通过全文检索和连接图帮助用户快速找回并理解知识关系。
- 支持标准格式导出以及可恢复的本地数据保护机制。

### 3.3 产品成功指标

首版产品达到以下条件时，可认为核心目标得到满足：

- 在第 11.1 节规定的参考环境和标准测试知识库下，启动、编辑、保存、检索、筛选、连接图和索引性能达到对应指标。
- 异常写入、异常退出、批量操作失败、配置或索引损坏时，符合第 11.2 节的数据完整性和可恢复性指标。
- 至少 5 名目标学生在不阅读说明文档的情况下完成“创建知识库—记录笔记—添加标签—建立链接—搜索找回”的代表性任务，整体任务成功率不低于 80%。
- 核心功能在 Windows 10 22H2 和 Windows 11 64 位、1366×768 分辨率及 125%/150% 缩放条件下可正常使用。
- 核心数据始终保存在用户选择的本地位置；离线状态下可以完成记录、组织、检索、关联、导出、备份和恢复。

上述指标属于产品验收目标；在本次需求分析作业中通过需求审查和可行性证据核实，不伪造尚未实施的软件运行结果。

## 4. 目标用户

### 4.1 主要用户

普通本科生，主要使用 Windows 笔记本电脑，需要按学期和课程管理课堂笔记、复习资料、作业说明、实验记录、图片及附件。

### 4.2 用户特征

- 具备基础电脑操作能力，但不要求熟悉复杂 Markdown 语法。
- 重视离线可用、数据自主保存、快速查找和资料关联。
- Markdown 初学者可使用工具栏完成常用格式操作。
- 熟练用户可直接输入 Markdown 语法并使用快捷键。
- 研究生和其他高校学生可以使用，但首版不为其建立独立角色。

## 5. 使用场景

### 5.1 最高频核心场景

1. `SC-01` 上课或自习时快速记录 Markdown 笔记、插入图片或课程附件，并自动保存。
2. `SC-02` 课后为笔记添加标签，并通过 Wiki 链接关联概念、课程和资料。
3. `SC-03` 复习或完成作业时，通过全文检索、标签和反向链接找回相关内容。
4. `SC-04` 整理作业或实验资料时，将任务说明、过程记录和附件集中保存在对应课程目录。

### 5.2 重要低频场景

1. `SC-05` 学期开始时创建本地知识库，并按学期和课程建立目录。
2. `SC-06` 将单篇笔记导出成适合他人阅读的文件并分享。
3. `SC-07` 更换设备、归档或发生异常时，备份或恢复整个知识库。

## 6. 产品范围

### 6.1 首版范围内

- 创建、打开和切换本地知识库。
- 文件夹和笔记的创建、重命名、移动、复制与删除。
- Markdown 编辑、预览、自动保存和异常恢复。
- 标签管理、全文检索、Wiki 链接和反向链接。
- 全局及局部知识连接图。
- 图片和常见学习附件管理。
- 单篇笔记导出。
- 完整知识库备份、恢复和回收站。
- 基础设置、明暗主题和界面状态记忆。

### 6.2 首版范围外

- 用户账号和云端存储。
- 跨设备自动同步。
- 多人实时协作和权限审批。
- 移动端、macOS 和 Linux 客户端。
- 第三方插件系统。
- 在线公开发布和社交平台直发。
- 内置生成式 AI、OCR 和附件正文识别。
- 笔记正文加密和知识库密码锁。

## 7. 信息组织模型

- 用户可以创建或打开多个相互独立的知识库。
- 知识库包含多级文件夹、Markdown 笔记、图片和其他附件。
- 每篇笔记在文件系统中只有一个实际位置。
- 一篇笔记可以拥有多个跨目录标签。
- 笔记之间通过 Wiki 链接形成多对多关联。
- 反向链接由系统自动计算。
- 文件夹表达稳定的学期或课程结构，标签表达跨目录分类，链接表达知识语义关系。

## 8. 文件与数据格式

### 8.1 笔记格式

- 每篇笔记是 UTF-8 编码的普通 `.md` 文件。
- 正文使用标准 Markdown。
- YAML 元数据保存唯一标识、标题、标签、创建时间和修改时间。
- 无法识别的 YAML 字段在读写时予以保留。
- 元数据异常不能导致正文丢失。

示例：

```markdown
---
id: note-a1b2c3
title: 数据结构复习
tags: [数据结构, 期末复习]
created: 2026-10-21T10:30:00+08:00
updated: 2026-10-21T11:20:00+08:00
---

# 数据结构复习
```

### 8.2 配置与附件

- 配置、搜索索引和界面状态保存在知识库内的隐藏配置目录中，不混入正文。
- 图片及附件使用相对路径引用。
- 外部修改 Markdown 文件后，应用重新扫描并更新内容。

## 9. 功能模块

> 本节只提供便于阅读的模块概览，不另行定义需求。第 15 节原子功能需求、业务规则、数据要求和验收用例是唯一规范性表述；若概览与第 15 节存在差异，以第 15 节为准。下列“对应编号”用于消除概览与原子需求之间的双轨解释。

### 9.1 知识库管理

对应编号：FR-KB-001～FR-KB-010、BR-001～BR-007、DR-KB-001～DR-KB-003。

负责创建、打开、切换和重新扫描本地知识库。

- 创建知识库时，用户选择保存位置并输入名称；系统创建独立文件夹和必要配置。
- 目标位置存在同名文件夹时不得覆盖，用户需更名或选择其他位置。
- 配置有效的已有知识库可直接打开。
- 仅包含普通 Markdown 文件的文件夹在展示扫描摘要并取得用户确认后，可初始化为知识库；初始化不得改写原有正文。
- 配置损坏时允许以安全模式打开原始文件，并重建配置和索引。
- 一个窗口同一时间只激活一个知识库；切换前保存当前编辑内容。
- 首版不允许多个应用实例同时写入同一知识库。检测到占用时默认只读打开，用户也可取消。
- 欢迎页显示最近打开的 10 个知识库；失效路径明确标记并可移除。
- 关闭当前知识库后返回欢迎页，不退出应用。
- 知识库文件夹被外部移动或重命名后，用户可重新定位；系统通过配置和唯一标识确认身份。
- 初始化普通 Markdown 文件夹前，系统显示笔记、附件、无法识别文件和异常文件的扫描摘要。
- 初始化只创建隐藏配置和索引，不立即改写原有 Markdown 文件。
- 无 YAML 元数据的导入笔记先使用隐藏索引中的临时稳定标识；用户首次在应用内编辑、添加标签或建立受管理链接时，系统在不改变原正文的前提下添加 YAML 元数据。
- 用户可以选择立即标准化全部笔记的元数据，但该选项默认不启用，执行前显示受影响文件数量。
- 已有合法 YAML 字段予以保留；重复 ID、格式错误和字段冲突进入异常清单，不静默覆盖。
- 图片、PDF 和 Office 文件等识别为附件但不解析正文；隐藏配置、临时文件和系统文件不作为笔记导入。
- 指向知识库外部的符号链接或目录连接不予跟随。
- 初始化失败时只清理本次未完成的配置和索引，不修改原始文件。

### 9.2 笔记与目录管理

对应编号：FR-NOTE-001～FR-NOTE-013、BR-008～BR-023、DR-NOTE-001～DR-NOTE-004。

负责文件夹、笔记、回收站和文件操作。创建新笔记时先要求用户命名；用户跳过或取消时使用“未命名笔记”，重名时追加序号。文件名是主要显示标题，应用内改标题时同步重命名文件并更新链接。

- 同一知识库内移动笔记时保留笔记 ID、创建时间、标签和恢复记录，并更新相关路径链接；附件不重复复制。
- 复制笔记时生成新 ID 和创建时间，默认名称为“原名称 - 副本”；正文、标签和出站链接保留，原笔记的入站链接不改指向副本。
- 复制笔记时复制其实际引用的专属附件，避免副本依赖原笔记的附件目录。
- 复制文件夹时递归复制内部内容并为笔记生成新 ID；复制集合内部链接改指向对应副本，指向集合外部的链接保持不变。
- 剪切粘贴等同于移动，复制粘贴生成新 ID。
- 同名冲突时由用户选择重命名、跳过或取消，不得静默覆盖。
- 批量移动或复制应全部成功或回滚，并显示进度、允许安全取消。
- 首版不支持直接跨知识库拖放或复制；跨知识库转移使用导出和导入。

普通删除进入回收站，默认保留 30 天。永久删除需二次确认，并询问是否清除短期恢复快照。长期备份保持不可变，只能定位或删除应用可访问的整份备份。

- 正文撤销和重做只作用于当前笔记本次打开期间；跨重启恢复使用紧急草稿与恢复快照。
- 新建、重命名、移动和移入回收站等文件操作完成后提供 10 秒撤销入口。
- 文件操作撤销遇到路径或名称冲突时不得覆盖现有内容。
- 批量操作只允许整体撤销；复制操作撤销时将本次副本移入回收站。
- 清空回收站、永久删除和覆盖恢复不提供普通撤销，必须事前确认。
- 文件操作历史只记录操作类型、对象、时间与结果，不记录正文。

### 9.3 Markdown 编辑与预览

对应编号：FR-EDIT-001～FR-EDIT-016、BR-024～BR-035、DR-EDIT-001～DR-EDIT-004。

- 支持 CommonMark、常用 GFM 扩展、代码高亮、脚注、LaTeX 数学公式和 Mermaid 预览。
- 采用 Markdown 源码编辑与预览，不提供完全所见即所得编辑。
- 用户停止输入 5 秒后自动保存；切换笔记、关闭标签或退出前立即保存。
- 连续输入时每 10 秒写入紧急草稿缓存，每 5 分钟最多生成一份恢复快照。
- 外部修改与本地未保存内容冲突时保留双方版本，由用户处理。
- 本地图片和附件只直接加载知识库内部文件；库外文件需先复制到附件目录。
- 远程图片默认不自动加载，只允许用户对当前内容执行单次加载；首版不保存永久信任站点。
- 普通网页链接仅在用户点击后调用系统浏览器；`file://`、脚本协议和危险协议不得直接执行。
- Mermaid、公式、代码高亮或局部 Markdown 渲染失败时，只在对应区域显示错误及源码位置，不阻断正文编辑和其他内容预览。
- 预览过滤脚本、事件处理属性、危险嵌入和自动播放媒体；过滤行为不得反向修改 Markdown 正文。
- 工具栏支持标题、强调、删除线、引用、列表、任务列表、代码、链接、图片、表格和分隔线，并优先作用于选中文本。
- 支持常用快捷键，以及区分大小写和全词匹配的笔记内查找替换；首版不支持正则表达式替换。
- 编辑器默认自动换行，代码或长文本可临时关闭；行号默认关闭且可在设置中开启。
- 编辑与预览分屏默认滚动同步，用户可关闭；大纲定位同时作用于源码和预览。
- 状态栏显示字数、字符数、光标行列和保存状态。
- 富文本粘贴默认转换为安全 Markdown；图片粘贴遵循附件导入规则。
- 外部修改冲突时保留上次成功保存版本、本地未保存版本和外部版本，默认并排显示差异。
- 用户可保留本地版、保留外部版、手动合并或分别保存；系统不得擅自覆盖或自动合并。
- 未被选为最终结果的版本先写入短期恢复记录；冲突副本使用新 ID 和包含时间的名称。
- 暂不处理冲突时暂停该笔记的自动保存，但继续写入紧急草稿；退出后保留双方内容和冲突状态。
- 冲突解决后重建对应笔记的搜索、链接和预览状态。
- 普通用户通过右侧属性面板管理标题和标签；YAML 区域默认折叠但可展开编辑，并记住展开状态。
- 系统字段在属性面板中只读，自定义 YAML 字段予以保留。
- YAML 格式错误时正文仍可编辑和保存，但依赖元数据的操作暂停并标出错误位置。
- 重复 ID、缺失必需 ID 或非法系统字段不得覆盖最后一次有效元数据。

### 9.4 标签与分类

对应编号：FR-TAG-001～FR-TAG-009、BR-036～BR-043、DR-TAG-001～DR-TAG-003。

标签模块只负责标签集合逻辑；跨关键词、目录、标签和时间的组合检索统一由 FR-SEARCH-006 负责。

- 支持多标签、层级标签、自动补全和跨目录筛选。
- 支持标签重命名、合并、删除和批量更新。
- 删除标签不删除笔记。
- 英文标签匹配不区分大小写，但保留首次创建时的显示形式。
- 首版不提供自动标签和 AI 标签推荐。
- 层级标签使用 `/` 分隔，笔记只保存完整标签，不额外写入隐含父标签。
- 点击父标签默认包含全部后代标签，用户可切换为仅精确匹配；管理页分别显示直接数量和含后代总数。
- 重命名父标签时同步更新后代路径；重命名与批量更新必须全部成功或回滚。
- 合并标签时转移全部关联并自动去重。
- 删除有子标签的父标签前，用户需选择仅移除父标签或删除整个子树，并查看影响数量。
- 英文标签匹配不区分大小写；保存时移除前后空格，拒绝空标签和空层级。
- 支持多标签“同时满足”和“满足任一”，默认采用“同时满足”；支持排除标签。
- 关键词、文件夹、标签和修改时间等不同类别条件之间采用“同时满足”。
- 筛选条件在当前应用会话内保留，重启后默认清空；界面展示所有生效条件并支持一键清除。
- 标签补全优先名称匹配，其次参考最近使用和关联数量，但不自动添加标签。

### 9.5 检索与导航

对应编号：FR-SEARCH-001～FR-SEARCH-007、FR-NAV-001～FR-NAV-005、BR-044～BR-058、DR-SEARCH-001～DR-SEARCH-002、DR-NAV-001～DR-NAV-003。

- 检索标题、正文、标签、路径和附件文件名。
- 支持中英文、即时结果、命中高亮、筛选和排序。
- 不进行图片 OCR 或附件正文解析。
- 支持多标签页、临时预览标签、固定标签、前进、后退、最近使用和大纲定位。
- 记住上次打开的笔记和视图状态。
- 未加引号的多个关键词默认全部满足；双引号内容按完整短语匹配。
- 中文支持词语和连续字符匹配，英文不区分大小写并支持单词前缀匹配。
- 默认相关度依次考虑标题完全匹配、标题包含、标签、章节标题、路径和正文，再按命中次数及修改时间排序。
- 结果显示标题、路径、匹配字段和最多三个高亮片段；用户可改按修改时间或标题排序。
- 当前已打开笔记的未保存内容参与搜索并标记“未保存”。
- 回收站不参与普通搜索，但提供回收站内搜索；隐藏配置、索引、快照和备份永不进入结果。
- 搜索查询只在当前应用会话内保留，重启后默认清空。
- 同一窗口内同一笔记最多存在一个标签页；再次打开时切换至已有标签。
- 单击使用可替换的临时预览标签；双击、开始编辑、固定或按住 `Ctrl` 打开时转为固定标签。
- 导航历史记录笔记 ID、标题位置、滚动位置和光标位置，最多 100 个节点，只在当前会话保留。
- 内部链接、搜索结果、反向链接和连接图跳转均进入历史；大纲跳转记录标题位置，普通滚动不记录。
- 每个知识库持久保存最近 20 篇笔记；重启恢复已打开标签和活动笔记，但不恢复完整历史栈。
- 缺失笔记在历史或恢复标签中明确标记，不创建空白替代文件。

### 9.6 链接与知识图谱

对应编号：FR-LINK-001～FR-LINK-008、FR-GRAPH-001～FR-GRAPH-005、BR-059～BR-073、DR-LINK-001～DR-LINK-002、DR-GRAPH-001～DR-GRAPH-003。

- 支持 `[[笔记名称]]`、显示别名和章节级链接。
- 输入 Wiki 链接时提供补全和同名笔记消歧。
- 应用内移动或重命名笔记时自动维护引用。
- 外部操作造成的无法恢复引用标记为失效链接。
- 反向链接展示来源和引用上下文。
- 提供全局连接图和以当前笔记为中心的局部连接图。
- 连接图支持节点打开、搜索、筛选、缩放、拖动和按需展开。
- 默认隐藏孤立笔记，但允许用户显示。
- 连接图按需加载，不在启动时自动加载。
- 全局图默认使用力导向布局；局部图默认只加载当前笔记的一层相邻节点并允许逐步展开。
- 节点支持搜索、筛选、缩放、平移、重置、重新布局、信息查看和双击打开。
- 拖动节点只改变显示位置；用户固定的位置跨重启保存在知识库界面配置中。
- 相同来源和目标的多次链接合并为一条边并显示引用次数；方向在悬停或选中时强化。
- 当前、选中和搜索命中节点同时使用颜色以外的标记区分。
- 回收站、备份和快照不作为普通节点；失效目标以警告节点或面板统计呈现。
- 首版连接图只用于观察和导航，不允许拖拽连线直接修改 Markdown 链接。
- 筛选和临时展开状态只在当前会话保留，固定节点位置可以跨重启保留。
- 链接先匹配当前文件夹同名笔记，再匹配知识库内唯一同名笔记；多候选时必须由用户消歧。
- 自动补全选择多义目标后保存可唯一定位的相对路径；别名只影响显示文字。
- 章节不存在时仍打开目标笔记顶部并提示章节失效；缺失笔记链接允许用户在可选位置创建。
- 代码块、行内代码和转义 Wiki 文本不参与链接解析。
- 应用内重命名或移动只更新目标定位部分，保留别名和章节；外部变化无法唯一恢复时标记失效。
- 反向链接按来源笔记分组，显示引用次数和最多三个上下文片段，并可查看各引用位置。
- 指向回收站笔记的链接显示独立状态，不与普通失效链接混淆。

### 9.7 图片与附件

对应编号：FR-ATT-001～FR-ATT-011、BR-074～BR-086、DR-ATT-001～DR-ATT-004。

- 支持拖放、粘贴和文件选择器导入。
- 外部文件默认复制进知识库的附件目录，并使用相对路径引用。
- PNG、JPEG、GIF、WebP 和 BMP 可直接显示；SVG 经安全过滤后显示；PDF 可本地预览；DOCX、XLSX、PPTX、TXT、CSV 和 ZIP 由系统默认程序打开。
- 同名附件不得静默覆盖。
- 删除笔记前检查附件是否仍被其他笔记引用。
- 支持检查和清理未引用附件。
- 打开可执行文件、脚本或来源不明附件前给出安全提示。
- 附件统一保存在附件根目录下，并按笔记 ID 建立专属子目录。
- 导入时保留原文件名；非法字符安全替换并保留原名称显示；同名时追加序号且不覆盖。
- 同一笔记重复导入内容相同的文件时默认复用，并允许保留副本；不同笔记之间不自动去重。
- 单个附件超过 100 MB 时导入前再次确认，且不自动生成应用内预览；首版无额外硬上限。
- PNG、JPEG、GIF、WebP 和 BMP 可直接预览；SVG 通过安全过滤后才能渲染；PDF 预览失败时允许外部打开。
- 附件复制使用临时文件，完整复制和校验成功后提交；失败或取消时清理不完整临时文件。
- 附件列表展示名称、类型和大小，不把来源路径长期写入正文。
- 删除附件前扫描并展示全部活动引用；仍被引用的附件默认禁止直接删除。
- “删除文件并移除全部引用”必须事务更新 Markdown 和附件，失败时整体回滚。
- 普通附件删除及未引用附件清理均移入知识库回收站，遵循 30 天保留规则。
- 未引用检查只扫描附件目录中的活动文件，不处理配置、备份、快照或库外文件。
- 外部附件缺失时显示占位和失效路径；可重新定位并默认复制回原笔记附件目录。
- 外部变化只有在校验值等证据能唯一确认时才自动恢复，不能仅凭同名关联。
- EXE、COM、BAT、CMD、PS1、VBS、JS、JAR、MSI、SCR、LNK，双扩展名或实际类型与扩展名不符的文件再次确认后才交由 Windows 默认程序打开；应用本身不执行附件。

### 9.8 导出、备份与恢复

对应编号：FR-EXP-001～FR-EXP-006、FR-BACKUP-001～FR-BACKUP-003、FR-RESTORE-001～FR-RESTORE-006、BR-087～BR-107、DR-EXP-001、DR-BACKUP-001、DR-RESTORE-001～DR-RESTORE-002。

- 单篇笔记支持 PDF、HTML 和 Markdown ZIP 资料包导出。
- 默认只导出当前笔记及其实际使用的附件，不自动包含关联笔记。
- 默认移除内部唯一标识和时间元数据；用户可以保留标签和标题。
- 自动恢复快照默认启用，用户可以关闭；每篇笔记默认保留最近 20 个版本。
- 长期完整备份只由用户主动创建。
- 完整备份包含 Markdown、附件和必要配置，不包含可重建索引与缓存。
- 恢复前后均进行完整性校验；默认恢复到新文件夹。
- 导出前显示格式、路径、包含内容、缺失附件、失效链接、远程资源和冲突的预检结果。
- PDF 默认 A4 纵向和打印主题，正文可选择并渲染支持的 Markdown；普通附件只显示名称及未附带说明。
- HTML 为单个自包含文件，嵌入本地图片但不嵌入普通附件；预计超过 50 MB 时再次提示。
- Markdown ZIP 包含当前 Markdown 及实际引用的本地图片和普通附件，并重写包内相对路径。
- 三种格式默认不抓取远程图片；只有用户在预检中明确选择时才允许单次下载并嵌入。
- 未包含的内部链接保留可读文字并标记目标未包含；默认移除内部系统元数据。
- 同名输出由用户选择覆盖、自动重命名或取消；导出经临时目标和校验后提交，失败不得影响原笔记。
- 长期备份只由用户主动执行，输出为位于知识库目录之外的 ZIP，默认文件名含知识库名称和时间。
- 默认备份活动内容、附件、回收站、必要配置和固定图位置；排除可重建索引、缓存、临时文件和日志。
- 恢复快照默认不包含，用户可主动选择；紧急草稿和未解决冲突内容默认进入独立 `recovery` 区域。
- 备份前尝试保存全部可正常保存内容，无法保存或存在冲突时必须预检并经用户确认。
- 备份清单记录知识库身份、版本、范围和每个文件的相对路径、大小及 SHA-256。
- ZIP 经临时写入、重新读取、数量和校验值验证后才能标记成功；取消或失败时清理临时文件。
- 普通备份不加密，选择目标位置前提示私人信息风险。
- 恢复前展示清单并校验 ZIP 结构、路径、数量、大小和 SHA-256；损坏备份不得普通恢复。
- 损坏备份可进入独立“抢救提取”目录，但不得标记为完整恢复。
- 默认恢复到新空目录，不合并到现有知识库；覆盖前必须先成功创建安全副本。
- 旧格式在临时目录迁移副本且不改原 ZIP；高于当前支持版本时禁止普通恢复。
- 恢复防止路径穿越、绝对路径、符号链接越界和异常压缩膨胀，并在临时目录完成校验后提交。
- 恢复后重建索引；`recovery` 区域的草稿和冲突只提示逐项处理，不自动覆盖正文。
- 取消、空间不足、权限失败或校验失败时清理临时结果，原备份及现有知识库保持不变。

### 9.9 设置与状态管理

对应编号：FR-SET-001～FR-SET-010、BR-108～BR-118、DR-SET-001～DR-SET-003。

- 左右侧边栏首次使用时默认展开。
- 用户调整后，恢复上次的展开或收起状态。
- 支持明暗主题、排序、字号和常用快捷键。
- 主界面左侧为知识库导航，中间为编辑与预览，右侧为大纲、属性、标签和反向链接。
- 全局设置包含主题、编辑器字体、字号、自动换行、行号和可定制快捷键；主题首次默认跟随系统。
- 首版界面语言仅提供简体中文，内容仍支持中文、英文和常见 Unicode。
- 外部链接和风险附件安全提示不得永久关闭。
- 每个知识库独立保存边栏状态、视图模式、滚动同步、标签页、活动笔记、排序、固定图位置、快照策略、回收站期限和最近笔记。
- 标签、搜索条件及图临时筛选和展开状态不跨应用重启保存。
- 设置即时生效且按作用域保存；非法数值不得写入。
- 恢复默认设置只修改设置，不删除任何笔记、附件、快照、备份或回收站内容。
- 配置损坏时使用安全默认值并保留损坏副本；配置迁移前创建副本，失败时回退最后有效版本。

## 10. 优先级

### 10.1 规则

- 高：支撑最高频核心场景，或直接关系数据安全；缺少时首版不能正常使用。
- 中：明显提高效率或覆盖重要低频场景，但暂时缺少仍有替代办法。
- 低：增强体验和高级能力，不影响核心工作闭环。

### 10.2 高优先级与首版裁剪

高优先级表示首版总体必须形成闭环，但为控制课程项目规模，分为两个交付关口；“首版收尾”不等于降为中、低优先级。

#### 10.2.1 首个里程碑必须完成

- 知识库创建、打开及普通 Markdown 文件夹初始化。
- 笔记和文件夹基本操作，以及新建笔记命名规则。
- Markdown 基础编辑、预览、5 秒自动保存与保存失败保护。
- 标签基本操作、基础全文检索及结果打开。
- Wiki 链接、链接补全和反向链接。
- 图片和常见附件导入。
- 回收站、紧急草稿及误删除恢复。
- 里程碑规模裁剪：至少覆盖 500 篇笔记、50 MB Markdown 和 2,000 条链接；用于尽早验证数据安全与核心流程，不替代第 16 节首版性能指标。

#### 10.2.2 首版收尾必须完成

- 外部修改三方冲突处理、索引重建和批量操作回滚。
- 全局及局部知识连接图的展示、导航和基本交互。
- 完整的组合筛选、链接维护、附件安全提示和首版设置保护。
- 完整备份、恢复与导出闭环中被标为高优先级的安全能力。
- 首版验收规模：按第 16 节的 5,000 篇笔记、500 MB Markdown、20,000 条链接和 2 GB 附件执行，不得以里程碑缩减规模替代。

连接图优先级复核：FR-GRAPH-001～FR-GRAPH-003 以及 NFR-PERF-007、NFR-PERF-008 均为高优先级，并列入首版收尾必做；FR-GRAPH-004～FR-GRAPH-005 中的高级筛选、孤立节点显示和辅助视觉定制可维持较低优先级，不影响基础图谱闭环。

### 10.3 中优先级

- 多标签页、历史导航和大纲。
- 层级标签、标签合并和批量更新。
- 失效链接检测和链接自动维护。
- PDF、HTML 和 Markdown 资料包导出。
- 完整知识库备份与恢复。
- PDF 附件预览。
- 恢复快照预览和版本选择。
- 明暗主题和界面状态记忆。

### 10.4 低优先级

- Mermaid 图表预览。
- 高级搜索筛选和多种排序。
- 未引用附件检查和清理。
- 连接图高级筛选、孤立笔记显示及标签辅助区分。
- 快捷键个性化设置。
- 历史备份定位辅助。

## 11. 非功能需求

> 本节是质量目标概览，第 16 节带唯一编号和验证方法的 NFR 是唯一规范性表述；若两节出现差异，以第 16 节为准。

### 11.1 性能

对应编号：NFR-PERF-001～NFR-PERF-010。

参考环境为 Windows 11 64 位、四核处理器、8 GB 内存和固态硬盘。标准测试知识库包含 5,000 篇 Markdown 笔记、500 MB Markdown 数据、20,000 条链接和 2 GB 附件。

- 冷启动并打开最近知识库不超过 5 秒。
- 打开 1 MB 以内笔记不超过 1 秒。
- 普通输入、滚动和格式操作响应不超过 100 毫秒。
- 停止输入 5 秒后触发的保存应在 1 秒内完成。
- 普通全文检索在 1 秒内开始显示，完整结果不超过 2 秒。
- 筛选和排序在 1 秒内更新。
- 2,000 个节点、10,000 条连线以内的连接图在 3 秒内首次展示。
- 更大连接图允许渐进加载，但 1 秒内显示加载状态且界面保持响应。
- 首次建立标准知识库索引不超过 60 秒，并显示进度。
- 后续采用增量索引。

### 11.2 可靠性与数据完整性

对应编号：NFR-REL-001～NFR-REL-007。

- Markdown 使用原子写入，写入中断不能破坏旧文件。
- 异常退出时，最多丢失最近 10 秒未写入紧急草稿的内容。
- 批量重命名、移动、链接和标签更新必须全部成功或回滚。
- 索引及配置损坏可重建，不能影响正文和附件。
- 备份与恢复均校验文件数量和校验值。
- 磁盘空间不足、权限不足、文件占用或设备断开时停止写入并保留可恢复状态。
- 错误日志不记录笔记正文。

### 11.3 易用性与无障碍

对应编号：NFR-USE-001～NFR-USE-008。

- 新用户在不阅读说明文档时，应在 3 分钟内创建知识库并保存第一篇笔记。
- 至少 5 名目标学生完成“记录—标签—链接—搜索”任务的成功率不低于 80%。
- 支持键盘访问主要功能，焦点清晰可见。
- 颜色对比度遵循 WCAG 2.1 AA，状态不能只靠颜色表达。
- 支持 Windows 125% 和 150% 显示缩放。
- 在 1366×768 下核心功能正常使用。
- 默认正文字号不小于 14 px，并允许调整。
- 错误提示说明问题、可能原因和处理办法。

### 11.4 隐私与安全

对应编号：NFR-SEC-001～NFR-SEC-007。

- 无需账号，不上传笔记、附件、标签或使用行为。
- 默认不收集遥测，错误日志仅保存在本机且不记录正文。
- 过滤脚本、危险 HTML、恶意协议和不安全嵌入。
- 文件操作必须校验真实路径，不能越出知识库范围。
- ZIP 导入和恢复防止路径穿越、越界覆盖和异常膨胀。
- 首版不提供内置加密，普通完整备份不默认加密，并在创建前提示隐私风险。

### 11.5 兼容性与可移植性

对应编号：NFR-COMP-001～NFR-COMP-008。

- 正式支持 Windows 10 22H2 和 Windows 11 64 位。
- 提供当前用户安装方式，不要求管理员权限。
- 完整支持本机 NTFS 磁盘。
- 可移动磁盘和第三方同步目录按普通本地目录处理。
- 不正式支持网络共享目录多人同时编辑。
- HTML 导出兼容主流浏览器，PDF 导出兼容常见阅读器。
- 支持中文、英文及常见 Unicode 字符。

### 11.6 资源占用

对应编号：NFR-RES-001～NFR-RES-004。

- Windows 安装包不超过 200 MB，安装后应用文件不超过 500 MB。
- 在 8 GB 内存参考机器打开标准知识库并空闲 2 分钟后，应用工作集不超过 500 MB。
- 可重建索引文件总大小不超过被索引 Markdown UTF-8 字节数的 150%，增量索引不得无限累积临时文件。

## 12. 系统边界与外部依赖

系统依赖 Windows 文件系统、文件权限、系统默认浏览器和默认文件打开程序。Markdown、公式、Mermaid、PDF 和连接图由本地组件解析或渲染，核心功能不得依赖远程服务器。以下编号条目是可验收的接口与环境依赖需求，而不是背景说明。

### 15.2.1 笔记与目录业务规则

| 编号 | 规则 |
|---|---|
| BR-008 | 文件和文件夹名称必须符合 Windows 文件系统规则，并满足实际路径长度限制。 |
| BR-009 | 同一目录内名称按 Windows 语义不得冲突；不同目录允许同名笔记。 |
| BR-010 | 笔记文件名是主要显示标题；应用内改标题时同步重命名文件和 YAML 标题，正文一级标题不自动改文件名。 |
| BR-011 | 应用内重命名或移动必须维护受管理路径链接，且失败时回滚。 |
| BR-012 | 移动保留笔记 ID，复制生成新 ID。 |
| BR-013 | 文件夹不得移动到自身或其后代目录中。 |
| BR-014 | 复制副本保留出站链接，但原笔记的入站链接不得自动改指向副本。 |
| BR-015 | 批量移动、复制与批量撤销以整体事务执行。 |
| BR-016 | 导航排序只影响显示顺序，不改变磁盘路径。 |
| BR-017 | 普通删除进入知识库回收站，默认保留 30 天。 |
| BR-018 | 仅由被删除笔记使用的附件可随同进入回收站；仍被引用的附件保留。 |
| BR-019 | 永久删除、清空回收站和覆盖恢复不提供普通撤销。 |
| BR-020 | 永久删除不得静默删除长期备份；只能按 D-015 处理应用可访问的整份备份。 |
| BR-021 | 文件操作撤销入口有效期为操作成功后的 10 秒；正文撤销与版本恢复不属于该历史。 |
| BR-022 | 无法识别的外部文件保留在磁盘上，应用不得擅自删除。 |
| BR-023 | 首版不支持直接跨知识库复制或拖放内容。 |

### 15.3.1 Markdown 编辑与预览业务规则

| 编号 | 规则 |
|---|---|
| BR-024 | Markdown 源码是正文事实来源；预览、过滤和渲染错误不得反向修改源码。 |
| BR-025 | 用户停止输入 5 秒后自动保存；手动保存以及切换、关闭和正常退出前立即保存。 |
| BR-026 | 连续编辑时每 10 秒写入紧急草稿、至多每 5 分钟生成一份快照，每篇笔记保留最近 20 份。 |
| BR-027 | 未解决外部修改冲突时暂停该笔记自动保存，但紧急草稿继续工作。 |
| BR-028 | 远程图片默认阻止，只允许用户对当前内容单次加载，不保存永久信任站点。 |
| BR-029 | 库外本地文件不能直接长期引用，必须先复制进知识库附件目录。 |
| BR-030 | 属性面板中系统字段只读；未知 YAML 字段保留；非法系统字段不得覆盖最后有效值。 |
| BR-031 | 首版保持 Markdown 源码编辑，不提供完全所见即所得或正则替换。 |
| BR-032 | 预览必须过滤脚本、事件属性、危险嵌入、危险协议和自动播放媒体。 |
| BR-033 | 冲突解决由用户决定；未采用版本先进入恢复记录，冲突副本生成新 ID。 |
| BR-034 | 默认分屏、滚动同步和首次边栏展开；用户调整后的界面状态被记住。 |
| BR-035 | 正文撤销历史只保证当前打开会话，跨重启使用草稿和快照恢复。 |

### 15.5.1 检索与导航业务规则

| 编号 | 规则 |
|---|---|
| BR-044 | 普通索引只包含活动笔记的标题、正文、标签、路径和附件文件名，不解析附件正文。 |
| BR-045 | 未加引号的多个关键词必须全部满足；双引号内容按完整短语匹配。 |
| BR-046 | 中文支持词语和连续字符匹配；英文不区分大小写并支持单词前缀匹配。 |
| BR-047 | 默认排序依次考虑标题完全匹配、标题包含、标签、章节标题、路径、正文、命中次数和修改时间。 |
| BR-048 | 每个搜索结果最多展示三个命中片段，并标明匹配字段和路径。 |
| BR-049 | 索引是可重建数据，损坏或重建失败不得修改正文和附件。 |
| BR-050 | 已打开笔记的未保存缓冲区优先于磁盘旧版本参与搜索，并明确标记。 |
| BR-051 | 回收站仅在独立范围搜索；配置、索引、快照和备份不得进入普通结果。 |
| BR-052 | 搜索及筛选状态仅在当前应用会话保留，重启后默认清空。 |
| BR-053 | 同一窗口中的同一笔记最多一个标签页实例。 |
| BR-054 | 单击使用临时标签；双击、编辑、固定或 `Ctrl` 打开转为固定标签。 |
| BR-055 | 链接、搜索、反向链接、连接图和大纲跳转写入历史，连续普通滚动不写入历史。 |
| BR-056 | 导航历史最多 100 项且不跨重启；上次打开标签和活动笔记可跨重启恢复。 |
| BR-057 | 最近笔记每个知识库最多 20 项，排除回收站和永久删除内容。 |
| BR-058 | 缺失历史或标签目标不得自动创建空白替代文件。 |

### 15.6.1 链接与知识图谱业务规则

| 编号 | 规则 |
|---|---|
| BR-059 | 链接解析先匹配来源所在文件夹，再匹配全库唯一同名笔记；多候选不得自动猜测。 |
| BR-060 | 别名只影响显示；自动补全在需要消歧时保存可唯一定位的相对路径。 |
| BR-061 | 缺失或歧义目标不得自动连接到同名文件。 |
| BR-062 | 章节缺失时打开目标笔记顶部，并明确提示章节链接失效。 |
| BR-063 | 缺失链接创建目标时默认当前文件夹，但允许用户修改位置。 |
| BR-064 | 应用内重命名或移动只更新目标定位部分，保留链接别名与章节，并与文件操作一并事务提交。 |
| BR-065 | 指向回收站目标与普通失效链接使用不同状态。 |
| BR-066 | 反向链接按来源分组，展示次数、最多三个片段并允许查看全部引用位置。 |
| BR-067 | 代码块、行内代码和转义文本不参与 Wiki 链接解析。 |
| BR-068 | 全局和局部图按需加载；全局默认力导向，局部默认一层邻居。 |
| BR-069 | 双击节点只负责打开笔记；拖动节点只改变显示位置。 |
| BR-070 | 首版不得通过连接图直接创建、删除或修改 Markdown 链接。 |
| BR-071 | 孤立笔记默认隐藏；回收站、备份和快照不作为普通图节点。 |
| BR-072 | 图搜索命中、当前笔记和选中节点必须使用颜色以外的视觉标记。 |
| BR-073 | 图筛选和临时展开只保留当前会话；用户固定的节点位置可跨重启保留。 |

## 16. 原子非功能需求

### 16.1 性能

统一测试条件：Windows 11 64 位、四核处理器、8 GB 内存、固态硬盘；标准知识库包含 5,000 篇 Markdown 笔记、500 MB Markdown 数据、20,000 条链接和 2 GB 附件。计时采用至少 5 次独立运行的中位数；冷启动测试不得预先启动应用进程。

| 编号 | 原子需求 | 来源 | 优先级 | 验证方法与通过标准 |
|---|---|---|---|---|
| NFR-PERF-001 | 系统冷启动并打开最近使用知识库的时间应不超过 5 秒。 | D-023 | 高 | 在统一测试条件下执行 5 次冷启动；中位数不超过 5 秒。 |
| NFR-PERF-002 | 系统打开 1 MB 以内 Markdown 笔记并进入可编辑状态的时间应不超过 1 秒。 | D-023 | 高 | 随机抽取 10 篇接近 1 MB 的笔记逐一打开；每篇中位数不超过 1 秒。 |
| NFR-PERF-003 | 普通输入、滚动和常用格式操作的界面响应时间应不超过 100 毫秒。 | D-023 | 高 | 记录输入、滚动和 5 种格式命令各 30 次事件延迟；95% 事件不超过 100 毫秒。 |
| NFR-PERF-004 | 停止输入 5 秒触发的自动保存应在随后 1 秒内完成。 | D-018、D-023 | 高 | 对 1 MB 以内笔记执行 20 次修改；保存均在触发后 1 秒内完成且内容一致。 |
| NFR-PERF-005 | 普通全文检索应在 1 秒内显示首批结果，并在 2 秒内显示完整结果。 | D-023、D-046 | 高 | 对标准知识库执行 20 个预置中英文查询；每次首批不超过 1 秒、完整结果不超过 2 秒。 |
| NFR-PERF-006 | 已有结果集合的筛选或排序应在 1 秒内更新。 | D-023 | 中 | 对不少于 1,000 条候选结果连续切换目录、标签、时间和排序；每次更新时间不超过 1 秒。 |

| NFR-PERF-009 | 标准知识库首次索引应在 60 秒内完成并持续显示进度。 | D-023、D-046 | 高 | 删除索引后重新建立 5 次；中位数不超过 60 秒，过程中可见进度且可取消。 |

## 18. 参考实现架构与技术可行性

> 本节是对需求可实现性的参考验证，不把具体框架版本固化为产品需求。实际开发应锁定并审查依赖版本；性能指标仍须通过实现后的测试证明。

### 18.1 参考架构

| 层次 | 建议技术与职责 | 关键边界 |
|---|---|---|
| 桌面容器 | Electron | 面向 Windows 打包；主进程持有受控的文件系统、系统对话框、外部打开和 PDF 导出能力。 |
| 界面层 | React + TypeScript | 实现三栏工作区、编辑器、设置、回收站、恢复界面和状态展示；不直接获得任意 Node.js 或文件系统能力。 |
| 安全桥接层 | Electron preload + contextBridge | 只暴露按用途划分、参数经过校验的白名单 IPC；验证消息发送方，不暴露通用命令执行、任意路径读写或原始 IPC 对象。 |
| 内容层 | 普通 Markdown、YAML 和相对路径附件 | Markdown 与附件是唯一真实用户数据；应用索引和界面配置损坏时可以重建，避免数据被专有数据库锁定。 |
| Markdown 渲染 | markdown-it + KaTeX + Mermaid | 分别处理 CommonMark/GFM 扩展、数学公式和图表；使用本地资源、HTML 清理和 Mermaid `strict` 安全级别。 |
| 检索索引 | SQLite FTS5 | 索引标题、正文、标签、路径和附件名；使用相关度、片段和高亮能力；索引仅作可重建派生数据。中文匹配采用 trigram 或经验证的自定义分词策略。 |
| 链接与图谱 | 链接索引 + Cytoscape.js | 从 Wiki 链接计算有向边、反向链接和全局/局部图；源链接仍保存在 Markdown 中。 |
| 数据保护 | Node.js 本地文件服务 + ZIP/哈希组件 | 执行原子写入、草稿、快照、回收站、手动完整备份和恢复预检；所有目标路径先解析并验证边界。 |
| 导出 | 安全 HTML 模板、Electron `printToPDF`、ZIP | HTML 内联或复制允许的本地资源；PDF 使用 A4 参数；Markdown 包含附件时打包 ZIP。 |
| 验证 | 单元、集成、端到端与故障注入测试 | 分别覆盖解析、路径、事务、搜索、链接图、导出、备份恢复和第 16 节非功能指标。 |

### 18.2 安全架构约束

- 渲染进程启用 `contextIsolation` 和进程沙箱，禁用 Node.js 集成，不加载远程应用代码。
- 使用限制严格的内容安全策略；应用内 Markdown 预览不允许脚本执行。
- 外部 URL 在协议、主机和用户确认通过后才交给系统浏览器；外部附件按风险类型再次确认。
- 所有 IPC 按命令定义参数结构、路径作用域和返回数据，不提供“读取任意文件”或“执行任意命令”的通用入口。
- 远程图片默认阻止；单次允许加载也不得获得本地文件访问能力。
- ZIP 和本地路径处理必须在主进程完成真实路径规范化，再检查知识库或用户明确选择的目标范围。

### 18.5 可行性结论

在 Windows 本地桌面应用、普通 Markdown 文件、可重建本地索引和成熟本地渲染组件的约束下，当前功能范围不存在必须依赖云服务或尚无实现路径的需求。参考架构能够为各需求提供实现入口，因此需求在技术上具备可行性；但性能、中文检索质量、导出一致性和大图响应仍属于必须通过原型或成品测试核实的风险，不在本需求分析阶段伪称已经达标。

## 20. 数据字典与交换格式

### 20.1 笔记 YAML 元数据

| 键 | 类型 | 必填 | 格式与约束 | 维护规则 |
|---|---|---|---|---|
| `id` | 字符串 | 是 | 新建笔记使用 UUID v4；导入的既有 ID 可匹配 `^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$`，但必须在知识库内唯一。 | 系统生成且属性面板只读；移动不变，复制生成新值；重复或非法时不得覆盖最后有效值。 |
| `title` | 字符串 | 是 | UTF-8，去除首尾空白后 1～255 个字符，并符合 Windows 文件名约束。 | 应用内修改时同步文件名；正文一级标题不自动覆盖该值。 |
| `tags` | 字符串数组 | 是，可为空数组 | 每项去除首尾空白；使用 `/` 表示层级；不得为空或产生空层级；英文匹配不区分大小写。 | 属性面板或 YAML 编辑器修改；保存前规范化并去重。 |
| `created` | RFC 3339 时间字符串 | 是 | 必须包含时区偏移，例如 `2026-10-23T09:30:00+08:00`。 | 首次创建时写入；普通编辑、移动和重命名不得改变。 |
| `updated` | RFC 3339 时间字符串 | 是 | 必须包含时区偏移，且不得早于 `created`。 | 每次成功提交正文或受管理元数据后更新。 |
| 其他键 | YAML 合法值 | 否 | 键名不得与上述系统键冲突。 | 原样保留；系统不理解的字段不得因读写而丢失。 |

YAML 使用 UTF-8，位于文件开头并由 `---` 包围。解析失败时正文仍可编辑，但依赖 ID、标签或时间的操作暂停；修复前保留最后有效系统元数据副本。

### 20.2 知识库内部目录

| 相对路径 | 类型 | 必填 | 内容与约束 |
|---|---|---|---|
| `.pkm/vault.json` | JSON 文件 | 是 | `schemaVersion`、`vaultId`、`displayName`、`createdAt`；`vaultId` 使用 UUID v4。 |
| `.pkm/index.sqlite` | SQLite 文件 | 否，可重建 | 全文、标签、链接、附件名和临时导入 ID 索引；损坏或删除不得影响 Markdown 与附件。 |
| `.pkm/ui-state.json` | JSON 文件 | 否 | 知识库级边栏、标签页、视图、排序、固定图位置和最近笔记状态。 |
| `.pkm/recovery/drafts/` | 目录 | 否 | 以笔记 ID 标识的紧急草稿及基准版本；不得进入普通搜索。 |
| `.pkm/snapshots/<note-id>/` | 目录 | 否 | 短期恢复快照；文件名使用 UTC 或含时区的可排序时间戳，默认每篇最多 20 份。 |
| `.pkm/trash/` | 目录 | 否 | 回收站内容及含原路径、删除时间和类型的元数据；默认 30 天。 |
| `attachments/<note-id>/` | 目录 | 按需 | 该笔记导入附件；文件名冲突追加序号，不允许通过相对路径越出目录。 |

`.pkm` 中的索引、缓存和界面状态是系统数据；除恢复专用入口外，不作为普通笔记或附件展示。应用初始化普通 Markdown 文件夹时只新增必要的隐藏结构，不批量改写原文件。

### 20.3 完整备份 ZIP 与 `manifest.json`

完整备份的根目录必须包含 `manifest.json` 和 `vault/`。`vault/` 保存选定范围内的知识库相对结构；所有 ZIP 条目使用 UTF-8 名称和 `/` 分隔符，不得包含盘符、绝对路径、`..`、符号链接或重复规范化路径。

| `manifest.json` 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `schemaVersion` | 正整数 | 是 | 备份格式版本；高于当前支持版本时禁止普通恢复。 |
| `backupId` | UUID v4 字符串 | 是 | 每次成功备份唯一。 |
| `vaultId` | 字符串 | 是 | 与 `.pkm/vault.json` 的知识库标识一致。 |
| `createdAt` | RFC 3339 时间字符串 | 是 | 含时区。 |
| `appVersion` | 字符串 | 是 | 创建备份的应用版本。 |
| `scope` | 对象 | 是 | 布尔字段：`activeContent`、`attachments`、`trash`、`snapshots`、`recovery`、`uiState`。 |
| `fileCount` | 非负整数 | 是 | 必须等于 `files` 数组项数。 |
| `totalBytes` | 非负整数 | 是 | 必须等于所有文件未压缩大小之和。 |
| `files` | 对象数组 | 是 | 每项包含 `path`、`size`、`sha256`、`type`；按规范化相对路径升序排列。 |

恢复前逐项验证路径、数量、大小和 SHA-256；清单与实际条目不一致时不得标记为完整恢复。旧格式迁移只操作临时副本，不改写原 ZIP。

### 20.4 单篇 Markdown ZIP

| 包内路径 | 内容 |
|---|---|
| `note.md` | 当前笔记；默认移除内部 `id`、`created`、`updated`，按用户选择保留标题和标签。 |
| `attachments/` | 当前笔记实际引用的本地图片和普通附件，仅包含可读取且通过预检的文件。 |
| `export-manifest.json` | `schemaVersion`、导出时间、原显示标题、文件清单、大小和 SHA-256；不包含知识库真实绝对路径。 |

路径重写规则：将 `note.md` 中已打包附件统一改写为 `attachments/<安全文件名>`；同名文件追加确定性序号；未包含的内部链接保留可读文字并标记“目标未包含”；任何路径规范化后越出包根目录的条目必须拒绝。导出先写临时 ZIP，重新读取并校验后再原子提交。

### 20.5 附件类型枚举

| 类别 | 扩展名 | 默认行为 |
|---|---|---|
| 直接预览位图 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp` | 校验实际类型后在应用内显示。 |
| 过滤后预览 | `.svg` | 清除脚本、事件属性、外部资源和危险链接后显示。 |
| PDF | `.pdf` | 实际类型正确且规模允许时本地预览；失败可外部打开。 |
| 常见学习文件 | `.docx`、`.xlsx`、`.pptx`、`.txt`、`.csv`、`.zip` | 显示名称、类型和大小，由 Windows 默认程序打开。 |
| 明确风险类型 | `.exe`、`.com`、`.bat`、`.cmd`、`.ps1`、`.vbs`、`.js`、`.jar`、`.msi`、`.scr`、`.lnk` | 显示完整名称、检测类型和风险；每次外部打开前再次确认，应用不得执行。 |
| 其他或类型不符 | 未枚举、双扩展名、扩展名与实际类型不符 | 不自动预览；显示风险并要求单次确认，无法识别时允许取消或仅保留文件。 |
