## 2. 本地自动验证

在 `apps/desktop` 执行：

```powershell
pnpm install --frozen-lockfile
pnpm verify
```

`pnpm verify` 依次执行：

1. 主进程、preload 和界面的 TypeScript 检查；
2. Vitest 自动测试；
3. electron-vite 生产构建。

## 3. Windows 打包

快速生成用于本机检查的解包目录：

```powershell
pnpm package:dir
```

解包检查结果位于 `apps/desktop/dist-check/win-unpacked/`，不会覆盖先前生成的正式候选包。

生成最终便携程序：

```powershell
pnpm package:win
```

最终便携程序默认位于 `apps/desktop/dist/`，这些构建目录已被 Git 忽略，不要把 `.exe` 直接提交到源码历史中。最终成品应通过 GitHub Release 或课程提交系统分发。

也可以在 GitHub 的 Actions 页面手动运行“生成 Windows 候选包”，完成后下载保留 14 天的构建产物。

## 4. 人工回归

复制 `docs/acceptance-vault/` 到仓库外，再使用副本执行 `05_测试与验收计划.md` 中的 MAN-01～MAN-10。至少核对：

- 新建两篇同名笔记不会覆盖；
- 手动保存和自动保存后的磁盘内容正确；
- 搜索中文、英文、路径和无结果状态正确；
- 保存后北京时间正确，`id` 与 `created` 不被修改；
- 外部修改冲突不会被静默覆盖；
- 关闭并重启后仍可打开最近知识库；
- 最终 `.exe` 不依赖开发服务器也能运行。
