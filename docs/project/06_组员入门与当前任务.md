本文是 `luyinuo605` 和 `Mingzi-zz` 加入项目后的第一份必读说明。目标是让三名成员在同一个仓库中独立开发、互相审查，并把改进结果稳定合并到 `main`。

## 1. 项目是什么

项目名称：大学生个人 Markdown 知识库。

它是一款 Windows 本地桌面软件，帮助大学生在自己的文件夹中创建、编辑、保存和预览 Markdown 笔记。笔记保存在本地，不依赖云端账号。

技术栈：Electron、React、TypeScript、electron-vite、Vitest。

仓库地址：<https://github.com/wangyizhou767/student-markdown-knowledge-base>

程序代码位于 `apps/desktop/`，项目说明位于 `docs/`。

## 2. 当前软件状态

截至 2026 年 10 月 28 日，`main` 已经能够：

1. 选择或重新打开最近使用的知识库文件夹；
2. 显示文件夹中的 Markdown 文件树；
3. 新建、打开、编辑和保存笔记；
4. 每 5 秒自动保存，并显示保存状态；
5. 实时预览经过安全处理的 Markdown；
6. 为新笔记生成唯一 `id`，并以北京时间记录创建时间；
7. 显示中文应用菜单；
8. 通过现有自动测试并打包为 Windows 程序。

尚需改进：笔记搜索、保存时自动更新 `updated`、更多测试、操作手册和最终安装包。

## 3. 第一次在本地运行

先在 GitHub 接受仓库邀请，然后在 PowerShell 中执行：

```powershell
git clone https://github.com/wangyizhou767/student-markdown-knowledge-base.git
cd student-markdown-knowledge-base/apps/desktop
pnpm install
pnpm dev
```

如果电脑没有 Node.js 或 pnpm，先安装 Node.js 22，再执行：

```powershell
npm install -g pnpm
```

运行测试和构建：

```powershell
pnpm test
pnpm build
```

## 5. 每位组员的 GitHub 操作

开始任务前：

```powershell
git switch main
git pull origin main
git switch -c feature/自己的任务名
```

开发过程中提交自己的成果：

```powershell
git status
git add 修改过的文件
git commit -m "feat: 简要说明完成的功能"
git push -u origin feature/自己的任务名
```

然后打开 GitHub 仓库，点击 `Compare & pull request`，目标分支选择 `main`。Pull Request 中必须写清：

1. 做了什么；
2. 修改了哪些文件；
3. 如何验证；
4. 测试或构建结果；
5. 界面功能附截图；
6. 关联自己的 Issue。

禁止三人共用同一个 GitHub 账号提交，也不要把 `node_modules`、个人测试笔记或本机绝对路径上传到仓库。
