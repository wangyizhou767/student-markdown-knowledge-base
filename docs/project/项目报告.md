## 1. 项目概述与 NABCD

### 1.1 项目概述

“大学生个人 Markdown 知识库”是一款 Windows 本地桌面软件。它把普通 Markdown 文件作为用户数据来源，提供知识库选择、文件树、笔记编辑、实时预览、保存和后续检索能力。软件采用 Electron、React 和 TypeScript 实现，不要求用户注册账号，也不把课程笔记绑定在专有云平台中。

### 1.2 NABCD 分析

- Need：大学生的课程笔记分散在不同文件中，普通文本编辑器缺少统一浏览、预览和知识关联能力；部分云笔记又存在格式锁定和迁移成本。
- Approach：使用用户可直接访问的 Markdown 文件夹作为知识库，通过桌面应用提供文件树、编辑、预览、检索和安全文件操作。
- Benefit：笔记可离线使用、可被其他编辑器读取、便于 Git 备份，用户即使不再使用本软件也能保留数据。
- Competitors：VS Code、Typora、Obsidian 等工具功能成熟；本项目不追求全面替代，而是聚焦课程要求下的小型、中文、可解释的软件工程实现。
- Delivery：通过 GitHub 管理源代码、Issues 和 Pull Requests，最终提供 Windows 可运行程序、操作手册、测试记录和项目报告。

## 2. 需求分析与范围

完整需求基线见 `docs/baseline/01_需求分析文档_1.2.md`。本轮 MVP 重点是“选择知识库—新建/打开—编辑—预览—保存—重启读取”的数据闭环，并逐步增加搜索、Wiki 链接、回收站和 Windows 打包。

详细范围见 `docs/project/02_MVP范围冻结.md`。高级图谱、复杂标签事务、SQLite 全文检索、多窗口和多格式导出明确延期，不把设计完成误写为功能完成。

## 3. 系统设计

系统设计基线见 `docs/baseline/02_架构与系统设计文档_1.2.md`。

应用分为四个主要部分：

1. Electron 主进程：管理窗口、系统对话框、本地文件读取和保存；
2. preload：只向界面暴露经过限定的知识库 API；
3. React 渲染进程：展示文件树、编辑器、预览和状态提示；
4. shared：定义主进程与界面共同使用的数据契约。

渲染进程不直接获得 Node.js 文件系统权限。所有文件路径都由主进程解析并检查是否位于已选择知识库内部，降低界面脚本越权访问本机文件的风险。
