# 大学生个人 Markdown 知识库操作手册

## 1. 软件说明

本软件是面向大学生的 Windows 本地 Markdown 笔记工具。笔记以普通 `.md` 文件保存在用户选择的文件夹中，软件不会要求注册账号，也不会自动把笔记上传到云端。

本文以 2026 年 10 月 28 日的 `main` 版本为基础。搜索、Wiki 链接、回收站等仍在开发的功能会明确标为“待合并”或“待实现”，不作为当前版本已完成功能。

## 2. 开发环境启动

开发环境需要 Node.js 22 和 pnpm。首次使用时在 PowerShell 中执行：

```powershell
git clone https://github.com/wangyizhou767/student-markdown-knowledge-base.git
cd student-markdown-knowledge-base/apps/desktop
pnpm install
pnpm dev
```

启动后会出现“学生 Markdown 知识库”窗口。关闭终端会同时结束开发版本。

## 3. 构建与运行

在 `apps/desktop` 中执行：

```powershell
pnpm test
pnpm build
```

最终交付前还需要使用项目打包配置生成 Windows 便携程序，并在另一台电脑或干净 Windows 账户中验证。最终 Release 下载地址将在发布后补充，未发布前不要把本地临时构建路径写成正式下载地址。

## 4. 选择知识库

1. 启动软件；
2. 点击选择知识库的按钮；
3. 在系统文件夹对话框中选择一个用于保存笔记的目录；
4. 软件扫描其中的 Markdown 文件，并在左侧显示文件树；
5. 再次启动软件时，会尝试重新打开最近使用的知识库。

建议为课程笔记单独建立文件夹，不要直接选择桌面、磁盘根目录或包含大量无关文件的目录。

## 5. 新建笔记

1. 打开知识库后点击“新建笔记”；
2. 在弹出的窗口中输入笔记名称；
3. 确认后，软件在知识库中创建 `.md` 文件并打开；
4. 如果同名文件已存在，软件会生成带数字的名称，避免覆盖原文件。

新笔记头部包含：

- `id`：自动生成的唯一标识；
- `title`：创建时输入的标题；
- `tags`：标签列表；
- `created`：北京时间创建时间；
- `updated`：更新时间。

`+08:00` 表示该时间比协调世界时快 8 小时，即北京时间。

## 6. 编辑、预览与保存

1. 在左侧文件树点击笔记；
2. 在编辑区输入 Markdown；
3. 预览区会显示处理后的 Markdown 效果；
4. 点击保存按钮可以手动保存；
5. 停止输入后，软件也会按当前设置自动保存；
6. 保存状态会显示正在保存、已保存或错误。

如果文件已被其他程序修改，软件会阻止旧内容静默覆盖磁盘版本。遇到提示时，先复制尚未保存的编辑内容，再重新打开磁盘文件进行比较。

## 8. Wiki 链接和反向链接

状态：待实现。计划支持在正文中输入 `[[笔记名]]` 打开目标笔记，并显示引用当前笔记的其他文件。当前版本不要把这部分用于正式演示。

## 9. 删除与恢复

状态：待实现。设计目标是把笔记移入知识库内部的应用回收站，而不是永久删除，并允许恢复到原路径。当前版本如需删除，请先备份后再在资源管理器中操作。

## 10. 常见问题

### 无法新建或保存

确认知识库文件夹允许当前 Windows 用户写入，并避免选择系统保护目录。如果文件正被其他程序占用，先关闭占用程序后重试。

### 找不到刚在资源管理器中加入的文件

使用软件中的刷新功能重新扫描知识库，或重新打开该知识库。

### 时间后面出现 `+08:00`

这是正常的时区标识，表示记录的是北京时间，不是附加的编号。

### 程序无法启动

开发版本先确认依赖已经安装；打包版本记录 Windows 版本、程序版本和错误截图，并在 GitHub 创建缺陷 Issue。

## 11. 退出前检查

确认界面显示“已保存”后再关闭软件。最终发布版本需要继续验证异常退出和自动保存场景；在验证完成前，重要笔记应保留额外备份。
