# 一周 MVP 范围冻结

## 目标

在保留完整需求和架构设计的前提下，于 2026 年 11 月 1 日完成一个可安装、可演示、不会轻易损坏用户 Markdown 文件的 Windows 桌面程序。11 月 2 日只作为提交缓冲，不安排新功能。

## 必须完成

| 能力 | 本周实现 | 保留的设计原则 | 验收结果 |
|---|---|---|---|
| 知识库 | 通过系统对话框选择或创建本地目录，记住最近知识库 | 本地优先；用户目录是数据来源 | 重启后可重新打开原目录 |
| 文件树 | 递归显示 `.md` 文件和文件夹，支持刷新 | 渲染进程不直接访问文件系统 | 外部新增文件刷新后可见 |
| 笔记操作 | 新建、打开、重命名、保存、移入回收站和恢复 | 路径边界检查；不永久删除 | 名称冲突和非法名称有提示 |
| 编辑器 | 纯文本 Markdown 编辑、未保存状态、手动保存和 5 秒自动保存 | 保存经 preload 白名单接口 | 写入失败时缓冲区内容仍存在 |
| 预览 | 标题、列表、代码、表格、链接和本地图片的安全预览 | 禁止脚本和危险协议 | 恶意 HTML 不执行脚本 |
| 搜索 | 启动/刷新时建立内存索引，按标题和正文搜索 | 派生索引可重建，不作为正文唯一来源 | 保存后搜索结果同步更新 |
| Wiki 链接 | 识别 `[[笔记名]]`、点击打开、显示基础反向链接 | 正文保持可读链接文本 | 同名或缺失目标给出提示 |
| 回收站 | 移入 `.pkm/trash/`，记录原路径并恢复 | 删除可恢复；冲突时不覆盖 | 恢复路径冲突时要求改名或取消 |
| 打包 | Windows 便携版或当前用户安装包 | 不需要管理员权限 | 在另一台或干净账户环境启动 |

## 明确延期

以下设计继续保留，但不纳入本周完成定义：SQLite FTS5、中文分词对比、连接图、复杂标签批量事务、完整三方冲突、附件风险识别、PDF/HTML/ZIP 导出、完整备份恢复、多窗口、高级设置、性能压力规模、五名用户统计性测试。

延期不等于删除需求。实现报告应标记为“设计已完成、当前版本未实现”，不得声称全部 109 项功能需求已经完成。

## 允许的降级

- 搜索由 SQLite FTS5 降级为有界内存索引，保留后续替换端口；
- 标签只读取 YAML 中的简单 `tags` 数组，不实现重命名、合并和子树删除；
- 自动保存采用单笔记串行写入，不实现完整三方冲突；发现磁盘版本变化时停止保存并提示重新加载；
- 回收站只保证应用内删除可恢复，不接管用户在资源管理器中的删除；
- 首版只提供一个应用窗口和一个活动编辑区。

## 停止线

如果 10 月 30 日晚仍不能稳定完成“打开知识库—编辑—保存—重启读取”，立即暂停 Wiki 链接和标签，把全部人员转入核心数据闭环、测试和打包。任何新增功能都不得牺牲保存正确性和可独立运行程序。
